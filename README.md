# Zen Keyboard Custom (ASUS ZenUI Style)

Keyboard Android kustom bergaya ASUS ZenUI dengan baris angka permanen dan dukungan simbol tekan-lama (long-press).

## Cara Build APK di GitHub
1. Upload seluruh isi proyek ini ke repositori GitHub.
2. Buka tab **Actions** dan jalankan workflow **Build Android APK**.
3. Setelah selesai, unduh file **zen-keyboard-debug-apk** di bagian **Artifacts**.
